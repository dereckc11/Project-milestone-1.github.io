Seven Key Concepts to Understand

These terms explain the core technologies, protocols, and security layers a web browser relies on to turn code into a safe, interactive webpage.

1. URL (Uniform Resource Locator)

A Uniform Resource Locator identifies where a web resource can be found on the internet. Before loading a page, the browser uses the Domain Name System (DNS) to translate the domain into a numeric server IP address.

  • Protocol: https:// tells the browser how to connect.
  • Domain & Path: ://example.com locates the host server and specific file.

2. HTTP and HTTPS

HTTP defines web request-and-response communication between a browser (client) and a web server. HTTPS wraps that traffic in TLS encryption and verifies the server's identity with a digital certificate.

  • Common Methods: GET requests data; POST submits form data.
  • Status Codes: 200 OK (success), 404 Not Found, and 500 Server Error.

3. HTML (HyperText Markup Language)

HTML describes the structure and meaning of page content, including headings, paragraphs, links, images, and forms. It acts as the structural skeleton of every webpage.

  • Semantic Tags: Elements like <header>, <nav>, and <main> improve screen-reader accessibility and search indexing.

4. CSS (Cascading Style Sheets)

CSS controls visual presentation such as color, spacing, typography, and responsive layout without changing the underlying HTML structure.

  • Box Model: Every element is sized using content, padding, border, and margin.
  • Modern Layouts: Flexbox and CSS Grid adapt pages cleanly across phones, tablets, and desktops.

5. DOM (Document Object Model)

The Document Object Model represents the parsed HTML document as a live tree of objects in memory that JavaScript can inspect and modify in real time.

  • Dynamic Updates: Interactive features like quiz scoring, timers, and darkmode toggles work by updating DOM nodes without reloading the page.

6. Rendering Engine

This core browser component interprets HTML, CSS, and visual assets to paint the visible page on your screen such as Blink (Chrome, Edge), WebKit (Safari), and Gecko (Firefox).

  • Critical Rendering Path: Builds the DOM and CSSOM trees, calculates element layout geometry, and paints pixels to the display.

7. Sandboxing and Site Isolation

These modern security techniques restrict the effects of untrusted web code and keep unrelated websites separated in system memory so a compromised tab cannot harm your device.

  • Sandboxing: Locks each browser tab inside a restricted operating system process so malicious scripts cannot access local files, cameras, or system settings without permission.
  • Site Isolation: Ensures pages from different domains run in separate OS processes, protecting saved passwords and session cookies against side-channel attacks.

How They Work Together: From Click to Screen

Every time you type a web address or click a link, these seven concepts run in sequence within fractions of a second:

  1. Locate (URL): The browser reads the URL and looks up the server's IP address via DNS.
  2. Fetch (HTTPS): It opens an encrypted connection and sends an HTTP GET request for the page.
  3. Parse (HTML & DOM): As HTML arrives, the browser constructs the live DOM tree.
  4. Style & Paint (CSS & Rendering Engine): CSS rules are applied and the rendering engine lays out and paints the visible page.
  5. Protect (Sandboxing): The entire tab runs inside an isolated sandbox while you read or take a quiz.
