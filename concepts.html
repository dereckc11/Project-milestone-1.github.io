Seven Key Concepts to Understand

These terms explain the main work a browser performs behind the scenes.

1. URL

A Uniform Resource Locator identifies where a web resource can be found.

2. HTTP and HTTPS

HTTP defines web request-and-response communication. HTTPS protects that communication with TLS encryption and server authentication.

3. HTML

HTML describes the structure and meaning of page content, including headings, paragraphs, links, images, and forms.

4. CSS

CSS controls presentation such as color, spacing, typography, and responsive layout.

5. DOM

The Document Object Model represents the document as objects that scripts can inspect and modify.

6. Rendering engine

This component interprets web content and styles and produces the visible page.

7. Sandboxing and site isolation

These security techniques restrict the effects of untrusted code and help separate unrelated websites.
