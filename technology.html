How a Browser Works

When you open a website, the browser coordinates networking, parsing, rendering, scripting, and security.

1. Requesting a page

The browser interprets a URL, uses DNS to locate the server, and sends an HTTP request. The response may include HTML, CSS, JavaScript, images, fonts, and other files.

2. Parsing HTML and CSS

HTML becomes a Document Object Model (DOM) tree. CSS rules are parsed into style information that the browser uses to decide how elements should look.

3. Layout and painting

The browser calculates the size and position of visible elements, then paints text, backgrounds, borders, and images onto the screen. Changes can trigger additional layout or painting work.

4. JavaScript and interaction

A JavaScript engine executes scripts that can validate forms, update content, animate interfaces, and respond to user actions. Scripts can also introduce performance or security risks if poorly designed.

5. Engines and architecture

Rendering engines such as Blink, Gecko, and WebKit implement web technologies. Modern browsers often isolate content in separate processes to improve stability and security.
