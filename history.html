A Short History of Web Browsers

The browser evolved alongside the World Wide Web and the growing expectations of internet users.

1991–1993: The early web

Tim Berners Lee's WorldWideWeb software appeared in 1991, but was created in late 1990. CERN released the web software into the public domain in 1993, and NCSA Mosaic helped make browsing accessible to more people. By october 1993 the number of web servers globally surpassed 500.

1994–2000: Browser competition

Netscape Navigator, Microsoft Internet Explorer, and apache http server competed intensely throughout these years. Rapid feature development helped popularize the web, but inconsistent browser behavior made standards especially important.

2000s: More choices

Firefox, Safari, and other browsers expanded competition. Web standards and richer internet connections supported more complex layouts, multimedia, and web services.

2008 onward: Modern platforms

Chrome's launch helped popularize a minimalist interface and multiprocess architecture. Today's browsers support online documents, video meetings, gaming, shopping, learning, and many other application like experiences.
